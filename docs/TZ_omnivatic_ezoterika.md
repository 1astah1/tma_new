Дата консультации: 08.07.2026
Консультант: София (практикующий таролог)
Объекты доработки: сайт https://omnivatic.com/ + Telegram-бот (дублирует функционал сайта)

---

## 1. Цель и общая идея

Перестроить структуру сайта и наполнение эзотерических разделов так, чтобы они соответствовали реальным запросам аудитории (по опыту практикующего таролога), с упором на три самых востребованных направления: **Таро, руны, астрология**. Контент должен быть профессионального уровня (не «бред на три предложения»), иначе ни разделы, ни платные подписки работать не будут.

### 1.1 Портрет аудитории (из консультации)

- ~99% — женщины.
- Ядро: 23–45 лет (встречаются и 18–19, и старше).
- Топ-3 темы запросов (в порядке убывания):
  1. **Любовь и личные отношения** («он пропал», семья, чувства партнёра).
  2. **Деньги, работа, бизнес**.
  3. **Ближайшее будущее** — нейтральные прогнозы («что ждёт на неделе», «подарки судьбы»). Есть пул постоянных клиентов, возвращающихся каждые 2 недели именно за этим.

### 1.2 Жёсткие запреты

- ❌ **Никаких гаданий/раскладов на здоровье.** Ни в темах гаданий, ни в подписках. Позиция консультанта категорична: вопросы здоровья — к врачу. Это репутационный и этический риск.
- ❌ **Убрать «Транзиты»** — аудитория в них не разбирается, раздел мёртвый.

## 3. Раздел «Гадания» (онлайн-расклады)

**Эталон по структуре и UX: https://gadanie.online/** — «прям очень качественно и удобно сделан», известен в профессиональной среде. Отсюда берём структуру, рубрикатор и механику, НЕ копируя тексты дословно (см. §9 о контенте).

### 3.1 Что анализировать/парсить с gadanie.online

- Рубрикатор гаданий (теги): «Да или Нет», «На будущее», «На день», «На вопрос», «На любовь», «На любимого», «На желание», «На чувства», «На ситуацию», «На отношения», «На мужчину», «На совет», «На работу», «На судьбу». Тег «На здоровье» у них есть — **мы его НЕ переносим** (запрет §1.2).
- Список конкретных гаданий (на сайте их 100+): названия, описания механики, количество карт в раскладе, позиции карт и их смысл. Примеры: «Нравлюсь ли я ему?», «Гадание на любимого мужчину», «Что происходит между нами?», «Расклад "На бывшего"».
- UX-механика: пользователь выбирает гадание → мысленно задаёт вопрос → «тянет»/переворачивает карты → получает трактовку по позициям + общий вывод.

### 3.2 Типы гаданий к запуску (MVP → развитие)

Приоритет 1 (MVP):
- «Да / Нет» (1 карта Таро).
- «Карта дня» (см. §7).
- «На любовь» (3 карты: чувства, препятствия, перспектива).
- «На будущее / ближайшие события» (3–5 карт) — под самый частый нейтральный запрос.
- «Совет» (1–3 карты).

Приоритет 2:
- «На судьбу», «На отношения» (подробные расклады 5–7 позиций).
- Гадание на рунах (1 руна и 3 руны — см. §6).
- Цыганский расклад (36 игральных/цыганских карт) — как отдельная механика.

### 3.3 Техническая реализация

- Единый «движок раскладов»: расклад = конфиг (JSON/БД): id, название, категория, колода (таро/руны/цыганские), число позиций, для каждой позиции — название и роль в трактовке; допускаются перевёрнутые карты (флаг).
- Генерация результата: случайный выбор карт без повторов + подстановка текстов значений из справочника (§4, §6) с учётом позиции и перевёрнутости. Для «дорогих» раскладов — комбинированные тексты (значение карты в контексте позиции).
- Один и тот же движок используется сайтом и ботом (общий API).

## 4. Раздел «Таро: значение Арканов» (справочник)

Два источника, два уровня глубины:

### 4.1 Базовый уровень + колода: uznayvse.ru

Источник: https://uznayvse.ru/tarot-cards/meaning/

- Взять **классическую колоду** (Райдера–Уэйта — «всем известна и легко воспринимается») — изображения карт с этого сайта служат референсом, сами картинки закупить/сгенерировать/взять из public domain (оригиналы Райдера–Уэйта 1909 г. в общественном достоянии — это легальный путь).
- Спарсить структуру и содержание по всем **78 картам**: 22 Старших аркана + 4 масти по 14 карт (Жезлы/огонь, Пентакли/земля, Мечи/воздух, Кубки/вода).
- По каждой карте у них есть: базовое значение, **перевёрнутое значение**, **значения в сочетаниях** с другими картами. Всё это нужно в нашей модели данных.
- Парсинг простой: раздел `/tarot-cards/meaning/` содержит ссылки на все 78 карт — обходим списком, HTML статичный.

### 4.2 Профессиональный уровень: taro.lv («настольная книга таролога»)

Источник: https://taro.lv/ — по оценке консультанта, лучшая информация по арканам в рунете, используется профессионалами. **Именно отсюда брать основные тексты значений**, если хотим, чтобы «люди зачитались».

Особенности и решение проблемы навигации (консультант не нашла общий каталог):

- Каждая карта живёт на URL вида `https://taro.lv/ru/78_dverej/door_N`, где N = 1…78.
- ⚠️ **Нумерация «дверей» НЕ совпадает с канонической нумерацией арканов** (проверено: `door_16` — это аркан «Мир», хотя Мир — XXI аркан). Значит, при парсинге нельзя мапить номер двери на карту — нужно обходить все `door_1`…`door_78`, брать заголовок `<h1>` страницы (название карты) и строить таблицу соответствия. Это же решает проблему, которую озвучила консультант («нельзя открыть всю колоду целиком») — после парсинга у нас будет полный индекс.
- Структура каждой страницы (подтверждено на примере «Мир»), парсим посекционно:
  - блок ключевых слов/соответствий (каббала, астрология, оккультное значение);
  - «Общее значение в раскладе»;
  - «Личностное состояние»;
  - «На более глубоком уровне» (сакральный смысл);
  - «Профессиональная ситуация»;
  - «Финансовое и жилищное положение»;
  - «Личные отношения»;
  - (на других картах могут быть доп. секции — парсер должен собирать все h2/h3-секции динамически, а не по жёсткому списку).
- Объём текста на карту большой (35+ КБ страница) — это и есть ценность. Храним по секциям, чтобы выводить по сферам жизни.

### 4.3 Вывод на сайте

- Страница-каталог: вся колода визуально (78 карт, сгруппированы: Старшие / 4 масти), поиск по названию.
- Страница карты: изображение, краткое значение (уровень uznayvse), табы/аккордеон по сферам жизни (уровень taro.lv): общее, любовь, работа, финансы, личность, сакральный смысл, перевёрнутая, сочетания.
- Идея консультанта на будущее: режим «мини-обучение Таро» / «руководство пользователя» — последовательное изучение арканов (можно как фича подписки в боте, §8).

## 5. Раздел «Совместимость» (переработка)

**Эталон результата: https://in-contri.ru/** — «очень точно рассчитывает, всё по факту и мегаподробно», известен клиенткам.

### 5.1 Анализ: как это сделано у них

Парсить у in-contri нечего (результат генерируется расчётом), но методика описана у них же на странице. Полный расчёт совместимости по датам рождения складывается из 7 блоков:

1. Совместимость по **чакрам (биоритмам)** — 7 уровней, сравнение «мужских»/«женских» уровней, поиск сильных и конфликтных;
2. Совместимость по **знакам Зодиака**;
3. «Сценарии любви» — нумерология по **месяцам рождения**;
4. **Арканы Таро** — архетипы личностей по нумерологии дней рождения;
5. Современная нумерология: числа Сознания, Миссии, Судьбы, Итога, Матрица;
6. **Квадрат Пифагора** (психоматрица) — сравнение характеристик;
7. **Графики Судьбы и Воли** — жизненный путь по классической нумерологии.

Все алгоритмы — публичные эзотерические методики, реализуются формулами по дате рождения (редукция чисел, таблицы соответствий). Ключ качества in-contri — не «магия», а **объём и детальность текстовых трактовок** для каждой комбинации.

### 5.2 Что делаем

- Вход: две даты рождения (+ пол — как оформительское решение, как у эталона).
- Выход: многосекционный отчёт по методикам выше, с процентами/шкалами по блокам, но **без единой итоговой цифры** как догмы (эталон прямо пишет, что 100% совместимости не существует — этот тон сохранить).
- Этапность: MVP = чакры + зодиак + арканы (3 блока); далее добавляем нумерологию, квадрат Пифагора, графики.
- Контент: для каждого блока нужна база трактовок (например, 12×12 пар знаков зодиака = 144 текста; 22×22 пар арканов — можно генерировать шаблонно из описаний пар архетипов). Это самая трудоёмкая часть — закладываем копирайтера/LLM-генерацию с редактурой (§9).

## 6. Раздел «Руны»

### 6.1 Контент — уже есть

Консультант передала **готовые описания всех 24 рун Старшего Футарка** (Феу, Уруз, Турисаз, Ансуз, Райдо, Каньо, Гебо, Вуньо, Хагалаз, Наутиз, Иса, Йера, Эйваз, Перт, Альгиз, Соулу, Тейваз, Беркана, Эваз, Манназ, Лагуз, Ингуз, Дагаз, Отал). Тексты в приложении к консультации — **брать их как есть**, парсить ничего не нужно.

### 6.2 Структура данных руны

Из переданных описаний по каждой руне извлекаем поля:

- `name`, `number` (1–24), `symbol` (юникод-глиф ᚠᚢᚦ…), `element` — стихия руны (огонь / земля / воздух / вода / лёд / время);
- `meaning` — основное значение;
- `reversed_meaning` — перевёрнутое (⚠️ не у всех: например, Гебо перевёрнутой позиции не имеет — поле nullable);
- `combinations` — значения в сочетании с рунами каждой стихии (огонь/воздух/вода/земля/время) — в текстах это есть для каждой руны;
- особые парные сочетания (Ансуз+Альгиз, Ансуз+Уруз, Соулу+Тейваз, Альгиз+Манназ, Дагаз+Вирд) — отдельная таблица пар.

### 6.3 Функционал

- Справочник рун (каталог 24 руны + страница каждой).
- Гадание на рунах: «одна руна» (совет дня), «три руны» (прошлое/настоящее/будущее). Механика перевёрнутых рун и **сочетаний по стихиям**: при мультируновом раскладе движок определяет стихии выпавших рун и подтягивает соответствующие тексты сочетаний — это даст «умную» трактовку, которой нет у конкурентов.

## 7. «Карта дня» (сайт + бот)

Очень популярная механика («офисные клерки прям пищат»), формат мини-гороскопа.

- Пользователь раз в день «тянет» карту (или выбирает одну из N рубашек — как на скриншоте из консультации).
- Результат: карта + трактовка в формате «энергии дня»: общий тон дня, любовь, дела/деньги, совет. Тексты генерируются из справочника Таро (§4) — для карты дня нужен отдельный, более лёгкий и «гороскопный» вариант текста на каждую из 78 карт (или хотя бы на 22 старших аркана в MVP).
- Ограничение: 1 карта на пользователя в сутки (иначе обесценивается).
- В боте: ежедневный push с картой дня по подписке (см. §8) — «каждое утро получаешь карту дня».
- На сайте: блок на главной + отдельная страница.

Референс формата: пост «Карта дня 08.07» из канала Queen Tarot (скриншот в консультации) — короткие блоки: общий тон дня / дела / финансы / отношения / совет, с эмодзи-маркерами.

## 8. Бот: подписки и монетизация

Рекомендации консультанта по платным механикам (у нас уже есть ТГ-бот, дублирующий сайт):

1. **Пакеты по направлениям**, а не один тариф: «Астрология», «Таро», «Общий» (расклады + гороскопы + расчёты). Кому-то интересно одно направление — не заставлять платить за всё.
2. Самое популярное платное — **ежедневные подробные онлайн-расклады**: общий расклад дня на 3–4 варианта выбора, подробнее, чем бесплатные форматы.
3. **Карта дня** — ежедневная утренняя рассылка (может входить в любой пакет как retention-механика).
4. Возможная фича: **мини-обучение Таро** (последовательный курс по арканам на базе справочника §4).
5. Главное требование: контент подписки должен быть **уникальным и объёмным** — «если это бред на три предложения, зачем за это платить». Это требование к продакшену контента (§9), не к коду.

Тарифная сетка, цены и способ оплаты (Telegram Stars / карта) — вне рамок этого ТЗ, требует отдельного решения.

## 9. Контент-стратегия и правовые рамки парсинга

Важно: прямое копирование текстов с gadanie.online, uznayvse.ru и taro.lv — это (а) нарушение авторских прав, (б) SEO-суицид (неуникальный контент). Порядок работы:

1. **Парсим во внутреннюю базу знаний** (не в паблик): структуру, факты, тезисы, полноту покрытия тем.
2. **Рерайт/генерация**: на базе спаршенного пишем свои тексты (LLM-генерация с обязательной редактурой человеком, понимающим тему; финальную вычитку ключевых разделов в идеале согласовать с Софией).
3. Исключения:
   - **Руны** — тексты переданы консультантом напрямую, используем как есть (уточнить у Софии происхождение текстов на предмет прав).
   - **Изображения колоды** — использовать public-domain сканы Райдера–Уэйта или заказать собственную отрисовку в этой стилистике.
4. Технически парсинг: все три сайта — статичный HTML, достаточно скриптов на Python (requests + BeautifulSoup) с троттлингом 1–2 req/sec и кэшированием сырых страниц. Объёмы: taro.lv — 78 страниц; uznayvse — ~80 страниц; gadanie.online — ~15 страниц категорий + ~100 страниц гаданий.
